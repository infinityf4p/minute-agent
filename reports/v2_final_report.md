# minute-agent v2 最终报告

> 日期：2026-11-04。测试期（2024-01 至 2026-10）于 2026-11-04 02:20 打开，只打开了这一次（记录在 `runs/locked_test_openings.jsonl`）。
> 完整数据表见 [v2_results.md](v2_results.md)，workflow 的结构和用法见 [docs/workflow.md](../docs/workflow.md)。

## 1. 结论

1. **唯一在测试期稳健显著的是“底仓隔夜 T”**：持有固定底仓（按成交额选前 300 只、等权），收盘前卖出模型预测隔夜会跌的部分，次日开盘集合竞价买回。测试期 683 个交易日，按底仓市值计**每天 +2.65 到 +3.14 bp**（年化约 6.7%–7.9%），t 值 8–12，Holm 校正后仍显著，2 倍成本下仍有 +1.6 到 +2.1 bp/天，2026-07-06 前后都为正。
2. **最简单的固定基线和搜索出来的最好结果一样好**：基线 `baseline_T2_overnight_sell` 测试期 +2.81 bp/天；随机搜索种子 1 的终选 +2.82；agent 种子 1 的终选 +3.14。搜索没有在这个方向上带来明显增益。
3. **其他方向没有通过测试期**：
   - T1 横截面多头：只有随机种子 2 的终选为正，Sharpe +1.37，单独检验 p = 0.012，但 Holm 校正后 p = 0.26，不显著。
   - T3 尾盘买、次日开盘卖：6 个终选和基线在测试期全部为负。
   - T2 日内 T0：用 1 分钟 K 线不计成本时也几乎不赚钱（+0.27 bp/天），扣成本后为负。
   - T4 选股加做 T：都不显著。
4. **agent 没有比随机搜索更好，在训练期更容易过拟合**。agent 种子 0 和 1 把大部分预算花在 T3 上，训练期两折 Sharpe 达到 +2.5 到 +3.2，但验证期只剩 +0.2 左右，测试期为负。随机搜索的 T3 在训练期就是负的。T2 方向上，agent 在两个种子里只试了 1 个配置，而且选的是亏钱的日内模式。
5. **评估流程本身是可信的**：验证期和测试期目标值的秩相关为 +0.70；所有 T3 过拟合的配置都在验证期就被识别出来了（验证期接近 0 或为负）。没有发生“验证期好、测试期突然崩”的情况，只有正常的衰减。

## 2. 实验设置

| 项目 | 取值 |
|---|---|
| 数据 | A 股 1 分钟 K 线和日线，2016 至 2026-10，不含已退市股票 |
| 开关 | `allow_t0 = true`，`position_sizing = true`（所有会话相同） |
| 成本 | 佣金万 2.5（最低 5 元），过户费十万分之 1，印花税 0.1%，2023-08-28 起 0.05%，滑点 3 bp，单 bar 参与率上限 10% |
| 账户 | 1 亿元；T0 底仓每月按成交额选前 300 只、等权 |
| 搜索 | agent（DeepSeek-V4.1-Flash）和随机搜索，各 3 个种子，每个会话 100 次评估 |
| 训练期反馈 | 初筛 2021 年；同模板排前 30% 的再跑两折（2020、2021） |
| 验证期 | 2022–2023 年，只有评估器可见；每个会话每个模板取两折前 3 跑验证期，选最好的作为终选 |
| 测试期 | 2024-01 至 2026-10；23 个终选加 3 个固定基线，一次评估完 |
| 检验 | 日收益均值 t 检验，26 条流程一起做 Holm 校正；DSR 按模板计算，试验次数 N 取该会话里该模板的配置数 |

## 3. 结果

### 3.1 测试期：显著的流程（Holm p < 0.05）

| 流程 | 模式 | bp/天 | 2 倍成本 | 不计成本 | t | 每股每天往返次数 | 胜率 | 最大回撤 |
|---|---|---|---|---|---|---|---|---|
| p4-agent-s1:T2 | 隔夜，双向 | +3.14 | +1.99 | +4.29 | 8.4 | 0.20 | 60% | −1.9% |
| baseline_T2_overnight_sell | 隔夜，先卖后买 | +2.81 | +2.08 | +3.54 | 12.0 | 0.10 | 64% | −1.1% |
| p4-random-s1:T2 | 隔夜，先卖后买 | +2.82 | +2.05 | +3.59 | 10.6 | 0.10 | 64% | −1.4% |
| p4-random-s0:T2 | 隔夜，先卖后买 | +2.65 | +1.57 | +3.74 | 8.1 | 0.20 | 59% | −1.5% |
| p4-random-s2:T2 | 隔夜，双向 | +0.85 | +0.58 | +1.12 | 8.2 | 0.05 | 59% | −0.4% |

bp/天按底仓市值计算。最大回撤是叠加收益曲线的回撤，不含底仓本身的涨跌。

### 3.3 搜索阶段：agent 和随机的差别

| 模板 | agent 初筛次数 | agent 初筛中位数 | 随机初筛次数 | 随机初筛中位数 |
|---|---|---|---|---|
| T1 | 73 | −0.71 | 56 | −1.17 |

agent 的初筛中位数在每个模板上都更高，说明它能读懂反馈、往训练期好的方向走。但这些提升主要是对 2021 年的拟合：T3 在训练期从 −3.3 提到 +1.4，到了验证期和测试期就消失了。agent 各会话的分配也很不均匀：种子 0 有 61 次 T3，种子 2 有 58 次 T1。三个 agent 会话共用 DeepSeek tokens 约 4.5M。

### 3.4 2026-07-06 前后

主板 ST 涨跌幅限制在 2026-07-06 从 5% 改为 10%。T2 隔夜在前后两段都为正，大约 +2.6 到 +2.8 bp/天对 +2.1 到 +2.8 bp/天。T1/T4 在之后那段的超额普遍偏高（+5 到 +13 bp/天），主要来自 2026 年 7 月一个月（例如 agent-s0:T1 当月 +38 bp/天）。这一段只有约 80 个交易日，这个差异不作为结论。

## 4. 可以使用的 workflow

推荐直接用最简单的版本，即基线配置。搜索出来的最好配置并没有明显更好，参数越少越不容易过拟合：

```json
{
  "template": "T2",
  "target": {"kind": "overnight"},
  "t0": {"mode": "overnight", "direction": "sell_first", "size_frac": 0.5, "entry_q": 0.9},
  "features": [
    {"op": "ret", "window_min": [5, 30, 60, 240]},
    {"op": "realized_vol", "window_min": [30, 240]},
    {"op": "vwap_dev", "at": "decision_time"},
    {"op": "volume_profile", "buckets": ["open30", "mid", "last30"]},
    {"op": "last_n_min_stats", "n": 30},
    {"op": "jump_count", "threshold_sigma": 4},
    {"op": "daily_lag", "fields": ["ret", "turnover"], "lags": [1, 5, 20]}
  ],
  "label_norm": "rank", "cross_section_norm": "rank",
  "model": {"type": "xgb", "params": {"max_depth": 6, "lr": 0.05, "n_estimators": 200}},
  "train": {"window_years": 3, "retrain_every": "quarter"},
  "execution": {"style": "next_vwap"},
  "universe_filter": {"min_price": 2, "min_adv_pct": 20}
}
```

每天的操作：

1. 每月初按过去成交额选前 300 只股票，作为等权底仓。
2. 每天 14:50 用当天 14:50 及之前的分钟数据和历史日线算特征，用 XGBoost 预测每只底仓股票“从下一根 bar 成交价到次日开盘”的收益，模型每季度用过去 3 年数据重训。
3. 预测最差的 10% 股票，卖出底仓的 50%，按 14:51 那根 bar 的成交均价成交，受参与率上限和跌停限制。
4. 次日开盘集合竞价买回；涨停买不回的部分顺延。

完整的分层结构、开关、模板和运行方法见 [docs/workflow.md](../docs/workflow.md)。复现测试期结果的入口是 `scripts/run_one.py`（配置文件加 `test` 阶段），但测试期已经打开过一次，后续任何新想法都不应该再拿这段数据来挑选。

## 5. 局限和需要注意的地方

- **幸存者偏差**：数据不含退市股票。底仓选的是成交额前 300 的大票，受影响相对小，但 T1/T3 这类全市场选股的结果会偏乐观。
- **开盘集合竞价的成交假设**：回测按开盘价全额成交，没有冲击成本（冲击系数为 0）。卖出量是底仓的 50%，按 1 亿元账户、300 只股票算，每只每次约 17 万元，在成交额前 300 的股票里影响应该很小。账户规模放大到 10 亿以上时，需要用实际的集合竞价成交量重估。
- **只有 1 分钟 K 线**：没有盘口和逐笔数据，所以日内 T0 结论（不赚钱）只适用于这个数据粒度。
- **ST 状态靠价格推断**：2026-07-06 之后的规则变化只有 4 个月的数据。
- **DSR 对 T2/T3 没有参考价值**：这两个模板里有些配置交易很少，日收益方差接近 0，Sharpe 极不稳定，把基准线抬得很高，所以 T2/T3 的 DSR 都是 0。这两类的显著性以测试期 t 检验加 Holm 为准。
- **agent 的提示和预算**：只用了一个模型（DeepSeek-V4.1-Flash）和一种提示方式，每个会话 100 次。结论是在这个设置下 agent 不优于随机搜索，不代表所有 agent 设计都不行。

## 6. 下一步建议

1. **给 agent 加防过拟合的约束**：例如要求每个模板至少探索若干次，或者把两折之间的稳定性（而不是均值）作为反馈。目前 agent 会把预算集中在训练期分数最高的一个模板上。
2. **在底仓隔夜 T 上做容量和冲击测试**：加大账户规模，用集合竞价成交量估算冲击成本。
3. **按计划在下一阶段加入更高频的维度**：5 分钟或 1 分钟决策，日内多次调仓。
4. **补退市股票数据**，重跑 T1/T3。
