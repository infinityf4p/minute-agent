# P0 基线审计：IC 0.32 从哪来

> 2026-11-03。数据：验证期 2022–2023 的基线预测（LightGBM 和 GRU，14:50 决策、隔夜目标）。脚本：`scripts/p0_audit.py`，原始数字在 `runs/p0_audit.json`。

## 结论

1. **不是泄漏。** 预测力全部在"今天收盘 → 明天开盘"这一段：14:50→15:00 的 IC ≈ 0，说明特征没有偷看 14:50 之后的价格。在真实数据上跑的泄漏金丝雀（偷看次日开盘的特征）被拦下，正常特征通过。
2. **不是标签起点的问题。** 把起点从 15:00 收盘价换成可成交的 14:51–14:55 成交均价，IC 从 0.324 只降到 0.315。
3. **Pearson IC 高于 RankIC，主要来自不可成交的样本。** 剔除 14:50 或收盘时处于涨跌停的股票和推断的 ST 股后（约占 1.7%），Pearson IC 从 0.32 降到 0.25，RankIC 基本不变（0.21→0.20）。
4. **预测力几乎全部在空头端。** 按分数分十组，最低组隔夜平均 −64bp，最高组只有 +7.5bp，各组平均约 −8bp。模型擅长找出"明天会低开"的股票，但 A 股不能做空，只做多最高组时，毛超额只有约 15bp，低于每天完整买卖约 18bp 的成本。
5. **隔夜和次日日内反向。** 最低组次日开盘到收盘反弹 +25bp，最高组 −4bp。这与文献里的"隔夜与日内拉锯"一致。

## 对 v2 计划的含义

- **信号可用，但用法要变。** 只做多最高组吃不到空头端的预测力。有底仓时，"预测会低开的持仓在收盘前卖出、次日开盘买回"可以利用它：最低组隔夜约 −60bp，远高于一次回转约 12–15bp 的成本。这是底仓操作的一种（隔夜版的反 T），应该加进 T2 模板，作为 T0 之外的一个选项。
- **要在底仓股票池里复核。** T2 的底仓按规则固定为高成交额股票，信号在这个子集里是否同样强，要在 P2 单独验证。
- **报告 IC 时以 RankIC 和可成交样本为准**，Pearson IC 会被涨跌停样本抬高。
- **幸存者偏差**可能让"低开后反弹"显得更好看（后来退市的股票不在数据里），结论要打折扣。
