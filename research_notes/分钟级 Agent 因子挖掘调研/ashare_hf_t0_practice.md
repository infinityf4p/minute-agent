## (a) 高频因子低频化：券商如何用分钟/逐笔数据构建日频/月频选股因子

### Takeaway
券商金工的主流做法是：用分钟K线（以及 TICK 快照、逐笔成交）在每个交易日计算一个日内统计量（如高频偏度、下行波动占比、尾盘成交占比、量价相关性、改进反转、大单推动涨幅等），再取过去 T 日（月频 T=20，周频 T=5）的均值，作为横截面选股因子做**周/月调仓**。截至2020年报告，单因子月均 Rank IC 约 3%–5%、年化 ICIR 约 3–4，选股能力主要来自**空头端**；纯分钟数据就能构建其中约一半的因子。

### Cited Findings
- 海通量化团队《高频因子的现实与幻想》（2020-07-31）整理了基于分钟、TICK、逐笔数据的14个因子，测试设定为：对行业、市值、中市值、反转、波动率、换手率正交，**不考虑交易成本**；月频选股回看 T=20 日，周频回看 T=5 日。— [新浪转载](https://finance.sina.com.cn/stock/stockzmt/2020-07-31/doc-iivhvpwx8393150.shtml)
- 只用**分钟数据**的因子（月均 Rank IC / 年化 ICIR / 月均多空收益）：高频偏度 3.41% / 3.48 / 1.07%；下行波动占比 3.03% / 3.02 / 0.94%；**尾盘成交占比 4.86% / 3.59 / 1.62%**；高频量价相关性 4.09% / 3.33 / 1.18%；改进反转 4.33% / 3.74 / 1.40%；平均单笔流出金额占比 3.03% / 3.15 / 1.07%；大单推动涨幅 3.71% / 3.79 / 1.32%。— [新浪转载](https://finance.sina.com.cn/stock/stockzmt/2020-07-31/doc-iivhvpwx8393150.shtml)
- 需要 TICK 或逐笔数据的因子（月均 Rank IC / ICIR）：开盘后净委买增额占比 4.19% / 4.24；开盘后买入意愿强度 5.07% / 3.93；开盘后买入意愿占比 4.34% / 3.43；开盘后净主买强度 4.46% / 3.29；大买成交占比 4.35% / 1.96；开盘后知情主卖占比 2.86% / 2.51。— [新浪转载](https://finance.sina.com.cn/stock/stockzmt/2020-07-31/doc-iivhvpwx8393150.shtml)
- **多空不对称**：大多数高频因子的空头效应强于多头效应。例如尾盘成交占比多头月均 +0.52%、空头 −1.10%；高频量价相关性多头只有 +0.11%、空头 −1.07%。海通提出“空头虚拟变量”和“剔除空头组合”的用法：在中证500上，事前剔除空头组合使年化超额从 22.5% 升至 23.8%。— [新浪转载](https://finance.sina.com.cn/stock/stockzmt/2020-07-31/doc-iivhvpwx8393150.shtml)
- 指数增强中的增量：在沪深300上加入尾盘成交占比，年化超额从 10.56% 升至 12.32%，信息比率从 2.28 升至 2.51。报告总结称，加入高频信息使沪深300/500/800增强策略的年化超额提升 2.6% 以上（回测，未计交易成本）。— [新浪转载](https://finance.sina.com.cn/stock/stockzmt/2020-07-31/doc-iivhvpwx8393150.shtml)
- 尾盘成交占比的构造方法：把交易日切成半小时区间，计算各区间成交量占全天的比例，取过去 T 日均值；14:30 之后的尾盘成交占比选股效果最显著。— [BigQuant 转载 海通 20191113](https://bigquant.com/wiki/doc/20191113-ymHU4hirzV)
- 海通（2019-11-13）周频与月频对比：月频调仓下，全市场多数因子月均多空收益差在 1.5% 以上、Rank IC 均值在 7% 以上（未正交）；改为周频后选股效果明显下降；复合月频模型的 Rank IC 均值为 6.82%，Rank ICIR 为 6.15。— [BigQuant 转载](https://bigquant.com/wiki/doc/20191113-ymHU4hirzV)
- 广发证券《多因子Alpha系列（四十一）：高频价量数据的因子化方法》（2021-07-12）用 IC 和多空收益筛出12个因子，包括已实现偏度、日内收益率、尾盘半小时成交量占比、日内价量相关性等。该报告按**周度调仓**，IC 是因子与未来5个交易日收益的秩相关。— [搜狐转载](https://www.sohu.com/a/487327822_121118711)；[慧博](https://m.hibor.com.cn/wap_detail.aspx?id=41bd6a2de310d1bd06a1adfc1987e18a)；[BigQuant](https://bigquant.com/wiki/doc/xCReVHKVy1)
- 量价相关性的方向：日内“量价背离”的股票未来收益好于“量价同向”的股票，IC 均值约 −0.047（知乎个人研究）。— [知乎](https://zhuanlan.zhihu.com/p/73412043)。中金《高频因子手册》也称日内量价相关因子基本与未来收益负相关。— [雪球转载](https://xueqiu.com/1985440678/304398369)
- 数据源差异：上交所逐笔数据不含委托和撤单信息，深交所 TICK 实时推送而上交所按3秒批量推送，因此依赖委托数据的因子在沪深两市的覆盖不一致。— [新浪转载](https://finance.sina.com.cn/stock/stockzmt/2020-07-31/doc-iivhvpwx8393150.shtml)

### Inferences
- 对只有1分钟K线的 Agent 而言，海通14个因子中有7个（偏度、下行波动占比、尾盘成交占比、量价相关性、改进反转、单笔流出金额占比、大单推动涨幅）可以直接复现。其中“单笔/大单”类因子还需要分钟成交笔数；如果只有成交量和成交额，只能用近似。买入意愿、主动买卖、委托类因子需要 L2 数据，无法复现。
- 业内默认的“分钟数据 → 日度统计 → 20日均值 → 月/周调仓”流程，应当是 Agent 因子挖掘的首要支持模式。评估指标应包括：Rank IC、ICIR、分组/多空收益、**多头与空头分别的收益**，以及与风格因子（市值、反转、波动、换手）正交后的 IC。
- 周频调仓会降低 IC，但能提高 alpha 的捕获速度，代价是更高换手。由于高频因子的 alpha 大多在空头端，A股融券受限时只能用于“剔除/低配”，所以 Agent 应把“作为负面筛选”的效果单独评估。
- 公开测试大多不计交易成本，回测数字应视为上限。

### Gaps
- 没有找到这些因子在2023–2026年的公开样本外 IC 统计，也没有系统的容量与衰减（半衰期）数据，只有2024年初深度学习高频因子回撤的周报线索。

## (b) 底仓 T0 / 日内回转 / T0 算法：机制、约束、收益与风险

### Takeaway
在 T+1 制度下，底仓 T0 依靠已有底仓（自有或客户持仓；2024年7月暂停转融券后，融券券源基本不可用）做日内高抛低吸。正T是先买后卖，反T是先卖后买，收盘前把股数恢复到原状，赚日内价差。私募和券商算法对底仓的“增强”宣传口径多在 6%–15%/年，券商内部称整体约 8%，**均非独立核实的实测数据**。收益高度依赖个股波动和换手，存在单边行情回不来的风险。私募内部这类策略的容量占比很小（约 ≤10%）。

### Cited Findings
**机制**
- 正T（先买后卖）和反T（先卖后买）都依赖已有底仓，收盘前把持仓恢复原状，日终净持股不变；底仓数量决定当日可做T的上限。— [知乎：正T与反T](https://zhuanlan.zhihu.com/p/2025843592577523893)（经搜索摘要转述）
- 券商T0算法：用底仓或融券在 T+1 下实现日内回转，赚日内反向买卖的价差，收盘前恢复底仓股数，因此也叫“日内回转交易”。文中列出的算法提供商有卡方、跃然、迅投、非凸、自诚。— [新浪 2025-06-05](https://finance.sina.com.cn/roll/2025-06-05/doc-ineyyvpe9485211.shtml)
- 界面新闻举例：投资者持有1000股，算法在低点买入1000股，在高点卖出原有持仓；中银证券人士称“不留隔夜敞口”。— [界面新闻（约2025-05）](https://m.jiemian.com/article/12835024.html)
- 早期人工 T0 的容量瓶颈：每个 T0 交易员通常最多同时操作30–40只股票。— [界面新闻](https://www.jiemian.com/article/2673945.html)

**券商零售化（2025）**
- 2025年有20余家券商推出 T0 算法服务，包括中泰（齐富通）、天风（皓兴T0）、招商（智远T0）、中银、国融、山西证券。— [界面新闻](https://m.jiemian.com/article/12835024.html)；[新浪 2025-06-05](https://finance.sina.com.cn/roll/2025-06-05/doc-ineyyvpe9485211.shtml)
- 门槛示例：
  - 普遍要求资产 100万元。
  - 天风：净资产 ≥100万元且风险等级 C3 以上。
  - 招商：C4 以上，且前20个交易日日均资产达到50万元，覆盖约4,200只股票。
  - 中银：建议稳定持有3只以上中小盘股。
  - 来源：[界面新闻](https://m.jiemian.com/article/12835024.html)
- 费用：算法费约万0.5–万3。有券商在开通后每笔额外加收万分之二；另一例是佣金从万2.5升至万3。— [新浪 2025-06-05](https://finance.sina.com.cn/roll/2025-06-05/doc-ineyyvpe9485211.shtml)；[界面新闻](https://m.jiemian.com/article/12835024.html)
- 适合的标的：流动性高、波动大、有热点题材的股票。不适合的标的：流动性差、低波动、小市值、无题材的股票。招商称波动和换手越高越适合。— [新浪 2025-06-05](https://finance.sina.com.cn/roll/2025-06-05/doc-ineyyvpe9485211.shtml)；[界面新闻](https://m.jiemian.com/article/12835024.html)

**风险**
- 极端行情下（快速涨停/跌停），系统可能来不及平仓回转，导致单日亏损放大；系统故障也可能中断交易。— [界面新闻](https://m.jiemian.com/article/12835024.html)
- 实际案例：某投资者使用卡方 T0，算法在低位卖出大笔持仓，约半小时没有买回，单日亏损约2.5万元（标题写“一天亏4万”，与正文不一致）；另一投资者连续几天亏损，盈利一天不够覆盖费用。— [新浪 2025-06-05](https://finance.sina.com.cn/roll/2025-06-05/doc-ineyyvpe9485211.shtml)

### Inferences
- **可推算的盈亏平衡**：卖出印花税0.05%加双边佣金（约万2.5×2 加 T0 附加费万0.5–万3）、过户费等，一个回转的成本大约在 0.10%–0.15% 量级。因此单次回转的价差必须明显超过约10–15bp。这也解释了为什么 T0 只在高波动、高换手的股票上有效。（基于上文费率推算，非引用数字）
- “年化 8%–12% 增强”按**底仓市值**计；如果每日回转比例 × 平均每次净价差约为 3–5bp/日 × 250 日，就落在这一量级。这是对宣传口径的量级核对，不是实测。
- 只有1分钟K线时，Agent 可以做“分钟级信号 → 在底仓内做反T/正T，T日收盘前强制回补”的模拟。需要支持的约束包括：
  - 卖出量 ≤ 可卖底仓；
  - 当日买入不可卖；
  - 收盘回补（若失败则记为敞口和库存风险）；
  - 涨跌停或停牌时不可成交；
  - 卖出印花税。
- 但公开资料显示，业界 T0 依赖 L2 逐笔或订单簿和亚分钟执行（卡方、非凸等是算法交易商），分钟级 T0 的 alpha 预计显著弱于宣传口径。

### Gaps
- 没有找到经审计或第三方的 T0 策略指数年度收益序列（华宝 PDF 未能解析出数值）。
- 没有找到每日回转次数、单只股票 T 仓占底仓比例（如 1/3、1/2）、预测周期（分钟 vs 小时）的权威公开数据；华泰、国泰君安 T0 算法的参数未检索到。
- 卡方、非凸等算法商的实盘绩效口径（按底仓市值还是可用资金）未披露。

## (c) 其他 A 股日内策略类型，以及只有1分钟K线时哪些现实可行

### Takeaway
学术与硕士论文证据显示，A股存在开盘半小时对尾盘的日内动量、开盘第1与第2个半小时之间的反转，以及因 T+1 导致的日内与隔夜收益的反转结构。尾盘成交占比作为横截面因子也很有效。在只有1分钟K线的条件下，最现实的是：
- 日频横截面因子（高频因子低频化）；
- 尾盘选股（14:30 后信号，14:50–15:00 或收盘集合竞价建仓，次日卖出）；
- 日内时间序列动量/反转（指数或ETF层面）。

依赖订单簿或逐笔的策略（盘口失衡、买入意愿、集合竞价挂单分析）无法实现。

### Cited Findings
- 用2015-06至2021-12的沪深300日内数据，发现开盘后第一个半小时至倒数第二个半小时的收益对最后半小时收益有正向预测力（疫情期间更强）；开盘后第一个半小时与第二个半小时收益显著负相关（反转）。来源是台湾硕士论文，证据等级低。— [airitilibrary](https://www.airitilibrary.com/Article/Detail/U0017-1912202210085140)
- 基于2000–2016年A股数据（中国学术期刊）的研究发现，A股存在日内动量和隔夜动量，两者之间因 T+1 存在较强反转；市场波动高时 T+1 约束更强、反转更强、动量策略更差。— [上海财大期刊 PDF](https://qks.shufe.edu.cn/J/PDFFullDown/A67fdee67-f823-44ad-8489-d42bcfae03ae)（经搜索摘要转述，未逐页核实）
- 中国市场日内时间序列动量的解释：知情交易者因U形成交量分布集中在开盘和尾盘交易。— [Journal of Futures Markets 2020, 40(4):632–650](https://ideas.repec.org/a/wly/jfutmk/v40y2020i4p632-650.html)；[vLex 摘要](https://law-journals-books.vlex.com/vid/intraday-timeseries-momentum-evidence-855674266)（该文样本可能为股指/期货，未核实具体标的）
- 尾盘（14:30后）成交占比是分钟数据中选股效果最好的因子之一（月均 Rank IC 4.86%）。— [新浪转载 海通](https://finance.sina.com.cn/stock/stockzmt/2020-07-31/doc-iivhvpwx8393150.shtml)
- 2026-07-06起，沪深交易所同步实施的新规还包括扩大盘后固定价格交易的适用范围、调整基金收盘交易机制等（媒体报道），这会影响收盘/盘后执行。— [同花顺 2026-07-06](https://news.10jqka.com.cn/20260706/c677987947.shtml)
- 日内私募案例显示 T0 alpha 受市场波动和成交额驱动：2024年9月后两市日成交额长期维持在万亿附近，相关策略表现较好；2025年4月后波动下降，表现转弱。— [新浪 2025-07-13](https://finance.sina.cn/2025-07-13/detail-inffikpp7564089.d.html)

### Inferences
- 按1分钟K线的可行性分级：
  - **高**：高频因子低频化的日频/周频横截面选股；尾盘选股或隔夜持有（T+1 下这是最自然的“短持有期”形态）；指数/ETF 层面的日内时间序列动量（首半小时 → 尾盘）。
  - **中**：底仓 T0 模拟（需要严格建模成本、不可卖约束和回补失败）；日内横截面反转（受 T+1 限制只能在底仓内实现）。
  - **低/不可行**：盘口/订单簿失衡、逐笔主动买卖、集合竞价挂单与撤单信息、亚分钟执行的 T0。
- 开盘集合竞价策略只能用开盘价和第一根K线近似，无法看到竞价过程中的未匹配量。
- 事件驱动的日内策略（公告、涨停板）需要新闻或公告数据与时间戳，并要建模涨跌停排队无法成交；主板 ST 改为10%涨跌停后，相关样本需要按日期区分制度。

### Gaps
- 没有找到 A 股“尾盘买入、次日早盘卖出”策略的权威券商研报或学术定量结果。
- A股个股层面首半小时 → 尾盘动量的顶刊证据未找到，现有证据为硕士论文或指数层面。
- 集合竞价策略的公开研究本轮未检索。

## (d) 业界评估方式与分钟级回测成交假设

### Takeaway
选股因子用 Rank IC、ICIR、多空/分组收益、多头与空头收益、指增年化超额、信息比率、超额最大回撤来评估。T0 通常用底仓市值上的年化增强收益（或“日均收益万X”）、胜率、最大回撤、夏普/卡玛来评估。公开资料几乎不披露分钟级成交假设，零售博文往往假设在信号价“精准成交”，属于乐观上限。

### Cited Findings
- 海通高频因子评估口径：月均 Rank IC、年化 ICIR、多空收益、胜率、多头与空头收益（相对等权市场）；指增口径为年化超额、信息比率、收益回撤比；未计交易成本。— [新浪转载](https://finance.sina.com.cn/stock/stockzmt/2020-07-31/doc-iivhvpwx8393150.shtml)
- T0 指数评估口径：年收益、年度最大回撤（<0.5%）、夏普、卡玛，并与市场中性指数比较。— [新浪 2025-06-05](https://finance.sina.com.cn/roll/2025-06-05/doc-ineyyvpe9485211.shtml)
- 零售 T0 推广口径：“日均收益万7”“胜率70%以上”“年化超额12%”。— [同花顺量化](https://quant.10jqka.com.cn/view/article/36UNU8G02Q154666OP6K1E0PPU)；[知乎](https://zhuanlan.zhihu.com/p/29473707749)；[界面新闻](https://m.jiemian.com/article/12835024.html)
- 一个公开的分钟级底仓 T 回测示例（宁德时代 300750，2026-09）：
  - 规则：以首根5分钟K线开盘价 ±0.5% 为上下轨，“假设每次都在上下轨精准成交”；
  - 成本：双边成本只用 fee=0.0006 近似；
  - 约束：每天最多一次回转，日终恢复底仓；
  - 结果：约21个交易日中10天完成回转；
  - 作者自评：结果仅为乐观上限，涨跌停日无法交易。
  - 来源：[掘金](https://juejin.cn/post/7683697497861324809)
- 海通有专题《高频策略交易成本的分析和预测》（2022-12），说明券商把交易成本建模作为高频策略的独立研究课题（仅标题）。— [lzw.me 研报索引](https://lzw.me/doc/quant-wiki/advanced/%E7%A0%94%E6%8A%A5%E7%B2%BE%E9%80%89/a%E8%82%A1%E9%AB%98%E9%A2%91%E7%A0%94%E6%8A%A5/)

### Inferences
- Agent 回测应默认采用比“信号价成交”更保守的规则，例如：
  - 信号在第 t 分钟收盘产生，以第 t+1 分钟开盘价或之后 N 分钟 VWAP 成交；
  - 设参与率上限（如分钟成交量的 5%–10%）；
  - 涨停不可买、跌停不可卖；
  - 卖出计 0.05% 印花税（2023-08-28 前为 0.1%），双边佣金约万2.5–万3，可选加 T0 算法费；
  - 加滑点。

  以上参数为推断性设计建议，非引用数字。
- T0 绩效应按底仓名义市值计算日均增强收益（bp/日），同时报告：回转成功率、未回补比例及其造成的隔夜敞口损益、日内最大敞口、成本后的盈亏平衡价差。

### Gaps
- 未找到券商或私募公开的分钟级成交假设标准（如下一根K线开盘、VWAP、参与率等的正式文件）。
- 未找到“日内回转成功率”的业界公开统计。

## (e) 2023–2026 年监管变化

### Takeaway
2023-08-28 印花税减半到 0.05%。2023-09 起沪深交易所对程序化交易实行报告制，并重点监控每秒 ≥300 笔或单日 ≥2万笔的账户。证监会《证券市场程序化交易管理规定（试行）》于2024-05-15发布、2024-10-08施行。沪深北交易所的实施细则于2025-04-03发布、2025-07-07施行，正式将“单账户每秒申报+撤单 ≥300 笔，或单日 ≥2万笔”认定为高频交易，并实施额外报告、从严监控和差异化收费。2024-07-11 起暂停转融券。主板 ST/*ST 涨跌幅自2026-07-06起由 5% 调整为 10%。

### Cited Findings
- 2023-09：沪深交易所通知规定未经报告不得进行程序化交易，单账户每秒申报/撤单 300 笔以上、单日 2 万笔以上的账户被列为重点监控对象。— [华尔街见闻](https://wallstreetcn.com/articles/3696980)；[每经 2023-09-01](https://nbd.com.cn/articles/2023-09-01/3001296.html)
- 证监会《证券市场程序化交易管理规定（试行）》：2024-05-15 发布，2024-10-08 施行；高频交易需额外报告服务器所在地、系统测试报告、故障应急方案等，交易所可适当提高高频交易收费；北向程序化交易纳入报告管理。条文数量有媒体报道称23条，也有报道称32条，存在冲突。— [同花顺 2024-05-16](https://news.10jqka.com.cn/20240516/c657883396.shtml)；[君合法评](https://junhe.com/legal-updates/2606)
- 沪深北交易所《程序化交易管理实施细则》：2025-04-03 发布，2025-07-07 施行。高频交易认定标准为“单账户每秒申报、撤单笔数合计最高达到300笔以上，或单日申报、撤单笔数合计最高达到20000笔以上”。细则明确了四类异常交易行为：瞬时申报速率异常、频繁瞬时撤单、频繁拉抬打压、短时间大额成交（后者按同一机构所有产品合并计算）。— [新华网 2025-04-07](https://www.news.cn/money/20250407/3142c6f5fd1d4b1ebd9eb91910befc5e/c.html)；[同花顺](https://news.10jqka.com.cn/20250407/c667241566.shtml)
- 差异化收费：有媒体报道征求意见稿拟对高频交易的流量费从每笔0.1元提高至1元，撤单每笔5元，但明确说明这只是征求意见版本，最终费率本轮**未核实**。— [华尔街见闻](https://wallstreetcn.com/articles/3721499)；[第一财经](https://www.yicai.com/news/102142848.html)
- 2024-07-11 暂停转融券；融券保证金比例下限提高到100%（私募120%），自2024-07-22执行。— [证监会](https://www.csrc.gov.cn/csrc/c100028/c7493852/content.shtml)
- 印花税：2023-08-28 起减半征收，由 1‰ 降至 0.5‰，向出让方征收。— [新华网](https://www.news.cn/2023-08/28/c_1212260850.htm)
- 主板 ST 涨跌幅：2025-06-27 首次就由 5% 改为 10% 征求意见；2026-04-10 沪深北交易所再次征求意见；2026-04-24 发布修订后的交易规则；**2026-07-06 起施行**。首日有6只主板风险警示股触及10%涨停；截至2026-07-03 沪深主板风险警示股超过150只。同期新规还扩大了盘后固定价格交易适用范围、调整了基金收盘交易机制。— [同花顺 2026-07-05](https://stock.10jqka.com.cn/20260705/c677956669.shtml)；[同花顺 2026-07-06](https://news.10jqka.com.cn/20260706/c677987947.shtml)；[北京商报](https://www.bbtnews.com.cn/2026/0705/598251.shtml)；[澎湃](https://m.thepaper.cn/newsDetail_forward_32942573)
- 期货市场另有《期货市场程序化交易管理规定（试行）》，2025-10-09 起实施，与证券规定不要混淆。— 同上搜索结果所引报道（[华尔街见闻](https://wallstreetcn.com/articles/3714978)，未逐字核实）

### Inferences
- 分钟级 Agent 的下单频率远低于每秒300笔或每日2万笔的阈值，不会被认定为高频交易；但若用于实盘，仍需履行程序化交易报告义务，并避免“频繁瞬时撤单”等异常行为模式。
- 回测数据集跨越2023-08-28（印花税）、2024-07-11（融券）、2026-07-06（ST 涨跌幅从5%到10%）几个时点，成本和涨跌停规则必须**按日期切换**，否则 ST 股的涨跌停可成交性和 T0 回测会出错。

### Gaps
- 高频交易差异化收费的最终生效标准，本轮未从交易所原文核实。
- 上述 ST 规则变更与程序化细则均来自媒体转述，未直接打开 sse.com.cn 或 szse.cn 原文。
- 暂停转融券后，券商自有券源融券和“融券 T0”在2025–2026年的现状未检索到。
